MISERIA — web promocional
========================

Estructura
- index.html
- assets/css/styles.css
- assets/js/main.js

Publicación
1. Sube la carpeta completa respetando la estructura.
2. Define index.html como página de entrada.
3. Para GitHub Pages, Netlify, Vercel o hosting tradicional no requiere compilación.
